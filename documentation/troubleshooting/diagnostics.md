# Troubleshooting by symptom

This page defines the target workflow and the checks required before release.

## Prerequisites and behavior

For an unavailable provider check profile, capabilities, model digest and approved route. For disk pressure identify namespace counters and pinned artifacts before pruning. For stuck tasks inspect lease epoch and external operation receipts.

## Procedure

For stale repository state re-pin and replan under grant. For uncertain push or PR, inspect remote ref and marker before retry. For incomplete cleanup keep reservations and inspect the supervisor record.

## Verification and recovery

Preserve exact error code and correlation identifier for support. Redact secrets before exporting diagnostics. A skip stays visible in evidence.
