# Installing and operating models

This page defines the target workflow and the checks required before release.

## Prerequisites and behavior

Select an immutable model manifest whose license, format, tokenizer and resource requirements are recorded. Match backend capabilities against the hardware profile.

## Procedure

Import local bytes or authorize a bounded download. Verify integrity before registration. Load only when RAM/VRAM and context fit, unload only after active generation ends or is safely cancelled.

## Verification and recovery

Inspect ModelReady and load evidence before relying on a model. A remote endpoint requires a distinct approved destination and disclosure scope.
