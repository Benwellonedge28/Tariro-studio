# Reference Vimbai documentation batch

This profile exercises the proposed documentation workflow on an authorized Vimbai repository. The test fixture uses synthetic paths and receipts.

1. Bind the repository identity, pinned base, expected branch state, approved paths and applicable `AGENTS.md` files to the assignment. Resolve the grant's documentation-only scope and exact 30-file count. Set one author in flight for this profile.
2. Inventory candidates under the same snapshot. Preserve substantive existing work. Freeze target order and requirement and evidence gates before authoring.
3. Draft, review and checkpoint one document at a time. Validate real source claims and store any approved forward-link obligations for final-tree review. A checkpoint binds the actual verified document bytes and evidence to the plan.
4. If interrupted after unit 17, revalidate all 17 durable checkpoints, then continue at 18. Resolve any uncertain transaction or external effect first.
5. Compare the full staged diff to the grant and verified output set. Reject a 31st file. A short final batch preserves progress and awaits a revised grant. A complete authorized batch must resolve all links, source claims, review findings and traceability gates before sealing.
6. On live approval, publish through a dedicated branch and open a draft PR with distinct durable effect identities. Reconcile a lost reply, verify the actual head and draft status, and record applicable check evidence.
