# Reference Vimbai documentation batch

This page defines the target workflow and the checks required before release.

## Prerequisites and behavior

Use the owner's authorized repository and policy with documentation-only mode. Scope the intended Markdown paths and require exactly 30 changed eligible files. Keep one concurrent author on the personal profile.

## Procedure

Inventory source and instructions, draft and check each file separately, persist verified checkpoints, seal diff, publish a dedicated branch and draft PR, and capture GitHub check outcomes.

## Verification and recovery

One extra file is rejected. Fewer than 30 eligible files await revised authorization. Source claims must resolve to the reviewed revision.
