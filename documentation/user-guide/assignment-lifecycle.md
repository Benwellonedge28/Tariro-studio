# Using assignments

This page defines the target workflow and the checks required before release.

## Prerequisites and behavior

An assignment binds workspace, repository, revision, approved scope, plan and resource budget. Plan and inspect the exact actions and verification requirements before execution.

## Procedure

Use status to see next verified unit, progress cursor, last checkpoint and active/blocked effects. Pause preserves verified work. Cancel stops new work and may leave an external effect in reconciliation. New approvals are required when scope widens or expires.

## Verification and recovery

Completion evidence identifies actual artifacts, hashes and external operation IDs. An agent narrative alone cannot establish the result.
