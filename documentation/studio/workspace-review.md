# Studio workspaces and review

This page defines the target workflow and the checks required before release.

## Prerequisites and behavior

Studio owns editor, repository, terminal, assignment, model and review presentation. Use gateway read models and event cursors for live views.

## Procedure

Show workspace and repository identity, pinned base, current diff, evidence and effects. Approval panels display exact grant scope, expiry and destinations; submitting yields a durable receipt. Render unsafe text as escaped data.

## Verification and recovery

A disconnected or stale client cannot imply approval. Reconnect by obtaining a snapshot and resuming cursor. Ensure keyboard users can inspect primary actions and review changes.
