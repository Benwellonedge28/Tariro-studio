# Independently authorized compensation

**ZIP-WORKFLOWS-COMPENSATION-001 · v1.1 candidate · Owner** Workflows maintainers

**Planned source** `crates/workflows/src/compensation.rs`

Create a compensation intent only from a confirmed original effect with exact target and evidence. Resolve the permitted remediation capability by review. Request distinct authorization binding original receipt, remediation digest, target, deadline, limits and expected current state. A forward grant, plan failure, cancellation or approval inferred from text cannot authorize compensation.

Where the approved remediation graph reverses dependency order, run independent keys only when conflict and resource checks permit. Persist the distinct effect key and one-use claim before dispatch. Revalidate current compensation scope immediately before the effect. Revocation denies the proposed operation. An in-flight uncertain result requires read-only reconciliation before a matching retry. Record verified remediation as Compensated while preserving the original result and receipts. Partial remediation retains per-effect status and keeps unresolved operations visible.

**ZIP-WORKFLOWS-COMPENSATION-T01.** Revoke the compensation grant after planning and before claim. Verify no effect call and preserve the original operation receipt and workflow failure evidence.
