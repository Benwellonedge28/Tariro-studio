# Zipporah

Zipporah Studio is a planned local-first, Safe Rust engineering environment for persistent, evidence-based assignments. The first reference workflow is a scoped Vimbai documentation assignment on a 16 GiB personal computer.

- [Master design](ZIPPORAH-STUDIO-DESIGN.md)
- [Architecture](ARCHITECTURE.md) and [requirements](REQUIREMENTS.md)
- [Subsystem dependency rules](specifications/0100-architecture/dependency-rules.md)
- [Delivery roadmap](ROADMAP.md)
- [Installation contract](documentation/getting-started/installation.md)
- [Contribution instructions](CONTRIBUTING.md)

The documentation defines target contracts and acceptance gates. Check release evidence before relying on any runtime, deployment or platform capability.
