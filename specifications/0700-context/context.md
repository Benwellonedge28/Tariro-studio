# Context assembly

**Contract version** 1.0. Master design §71.

## Contract

A context item records class, source revision and path/span, digest, trust class and measured tokens. Assemble trusted policy separately from untrusted source snippets. Preflight mandatory items before optional retrieval.

## Execution and integration

Order mandatory policy, assignment requirements, applicable pinned instructions and evidence before ranked context. Rank remaining snippets by relevance and stable digest tie-break; reject external promotion of restricted content. Record omission reason and count.

## Verification

Feed a repository instruction that requests unauthorized disclosure and verify it remains data. Use an oversized mandatory item set and verify fail-closed behavior.

Capture exact inputs, configured limits, actual result, policy revision and the evidence reference. Map applicable release requirements from [REQUIREMENTS.md](../../REQUIREMENTS.md).
