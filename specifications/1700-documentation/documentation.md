# Documentation engineering

**Contract version** 1.0. Master design §71.

## Contract

Require documented purpose, scope, dependencies, interfaces, data, algorithms, failures, security, limits, integration, tests and acceptance. A factual claim cites an immutable repository path and revision or an attributed external source.

## Execution and integration

Inventory existing substantive, missing and incomplete documents. Write and review one at a time, checkpoint verified files, then seal exact batch. For Vimbai, metadata and implementation files are excluded and short final batches pause.

## Verification

Validate links, traceability, incorrect references, empty placeholders, 30-file diff and re-opened checkpoints.

Capture exact inputs, configured limits, actual result, policy revision and the evidence reference. Map applicable release requirements from [REQUIREMENTS.md](../../REQUIREMENTS.md).
