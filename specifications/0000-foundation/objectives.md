# Objective evidence

**Contract version** 1.0. Master design §71.

Validate OBJ-001 through OBJ-016 according to the root objective matrix. An objective may be proposed, partially evidenced or accepted. Only the release owner sets Accepted after verifying mapped requirements and evidence digests. For partial evidence enumerate the supported platform, feature constraints and remaining release gate.

## Implementation and acceptance

A passing release records objective ID, release version, requirement IDs, evidence IDs and intended support level. Versions without evidence expose the capability as unavailable.
